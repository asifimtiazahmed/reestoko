# Reestoko Backend Setup & Infrastructure Guide

This guide explains how to set up and deploy the backend infrastructure for **Reestoko**. Since Cloud Firestore collections and security rules are already configured, this document provides the step-by-step instructions for both **Firebase Serverless Architecture** and **Custom OpenAPI / WebSocket Server Architecture**.

---

## 1. Firebase Console Configuration (Immediate Setup)

Since the Flutter app connects directly to Cloud Firestore, perform these 3 steps in [Firebase Console](https://console.firebase.google.com):

### A. Enable Firebase Authentication Providers
1. Go to **Authentication** -> **Get Started** -> **Sign-in method**.
2. **Anonymous Auth**: Enable *Anonymous* (Required for Incognito Guest Mode).
3. **Email/Password**: Enable *Email/Password*.
4. **Google Sign-In**: Enable *Google*, select your support email, and copy the Web Client ID.
5. **Apple Sign-In**: Enable *Apple*, set your Apple Developer Team ID & Services ID.

### B. Deploy Firestore Security Rules
Deploy the generated [`firestore.rules`](file:///Users/asifimtiazahmed/AndroidStudioProjects/reestoko/firestore.rules) file using Firebase CLI:
```bash
npx -y firebase-tools@latest deploy --only firestore:rules
```

### C. Seed Initial Test Data
Trigger `FirebaseSeedData.seedDemoData()` from the app settings screen or run a test script to seed demo users, families, and grocery stock.

## 2. Option A: Firebase Cloud Functions (Recommended Serverless Backend)

If you want automated background tasks (like sending push notifications when milk expires or auto-populating low stock items):

### Stack
- **Node.js 20 / TypeScript** using `firebase-functions/v2` and `firebase-admin`.

### Key Cloud Function Triggers

```typescript
// functions/src/index.ts
import { onDocumentUpdated } from "firebase-functions/v2/firestore";
import * as admin from "firebase-admin";

admin.initializeApp();

// Automatically queue item into Shopping List when stock hits low threshold
export const onStockUpdated = onDocumentUpdated("households/{householdId}/items/{itemId}", async (event) => {
  const newValue = event.data?.after.data();
  const previousValue = event.data?.before.data();

  if (newValue && newValue.quantity <= newValue.minThreshold && previousValue.quantity > newValue.minThreshold) {
    const shoppingListRef = admin.firestore()
      .collection("households")
      .doc(event.params.householdId)
      .collection("shopping_list");

    await shoppingListRef.add({
      name: newValue.name,
      quantityToBuy: 1,
      unit: newValue.unit,
      inventoryItemId: event.params.itemId,
      isPurchased: false,
      isAutoGenerated: true,
      addedBy: newValue.createdBy,
      createdAt: admin.firestore.FieldValue.serverTimestamp(),
    });
  }
});
```

## 3. Option B: Custom Dedicated REST API & WebSocket Server (Node.js / Express / ws)

If you are implementing the OpenAPI contract ([`docs/openapi.yaml`](file:///Users/asifimtiazahmed/AndroidStudioProjects/reestoko/docs/openapi.yaml)) and WebSockets ([`docs/websocket_feasibility.md`](file:///Users/asifimtiazahmed/AndroidStudioProjects/reestoko/docs/websocket_feasibility.md)) for your interview demo:

### Stack
- **Node.js Express / NestJS / Go**
- **Database**: Cloud Firestore Admin SDK (`firebase-admin`) or PostgreSQL.
- **WebSockets**: `ws` package listening on port `8080` / `wss://`.

### Step 1: JWT Authentication Middleware
Verify the client's Bearer token using Firebase Admin:
```javascript
const admin = require('firebase-admin');

async function authenticateToken(req, res, next) {
  const authHeader = req.headers.authorization;
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ code: 'UNAUTHORIZED', message: 'Missing token' });
  }

  const token = authHeader.split('Bearer ')[1];
  try {
    const decodedToken = await admin.auth().verifyIdToken(token);
    req.user = decodedToken;
    next();
  } catch (error) {
    return res.status(401).json({ code: 'UNAUTHORIZED', message: 'Invalid token' });
  }
}
```

### Step 2: WebSocket Broadcaster Server (`ws`)
```javascript
const { WebSocketServer } = require('ws');
const wss = new WebSocketServer({ port: 8080 });

const connections = new Map(); // householdId -> Set<WebSocket>

wss.on('connection', (ws, req) => {
  console.log('Client connected to WebSocket');

  ws.on('message', (message) => {
    const data = JSON.parse(message);

    if (data.event === 'PING') {
      ws.send(JSON.stringify({ event: 'PONG', timestamp: new Date().toISOString() }));
    } else if (data.event === 'SUBSCRIBE_HOUSEHOLD') {
      const householdId = data.payload.householdId;
      if (!connections.has(householdId)) connections.set(householdId, new Set());
      connections.get(householdId).add(ws);
    }
  });

  ws.on('close', () => console.log('Client disconnected'));
});

// Broadcast stock changes to household members
function broadcastStockUpdate(householdId, itemData) {
  const clients = connections.get(householdId);
  if (clients) {
    const payload = JSON.stringify({ event: 'STOCK_UPDATED', payload: itemData });
    for (const client of clients) {
      if (client.readyState === 1) client.send(payload);
    }
  }
}
```
